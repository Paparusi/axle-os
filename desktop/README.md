# Axle Desktop

Chưa làm. Bắt đầu sau khi Axle Server chạy ổn (Nhịp 5 trong `docs/ROADMAP.md`).

Dự kiến: lõi chung + giao diện + gõ tiếng Việt (fcitx5 + Bamboo) + driver GPU + agent nhìn và điều khiển màn hình.

Cần thử trước: Ubuntu 26.04 dùng GNOME trên Wayland, vốn chặn phần mềm chụp màn hình và giả lập bàn phím, chuột. Chọn giao diện sau khi đo thật, không chọn trên giấy.

# Lõi chung

Phần dùng chung cho Axle Server và Axle Desktop. Đang dựng ở Nhịp 1–3 (xem `docs/ROADMAP.md`).

- Snapshot btrfs tự động và lệnh quay lại.
- Vault: agent dùng khoá mà không thấy khoá.
- Công cụ MCP chung cho Claude, OpenAI, Conflux.
- Brain và memory dùng chung.
- Nhật ký lệnh agent.
- Mạng riêng (Tailscale, sau này Headscale).
